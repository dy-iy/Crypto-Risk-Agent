# 功能、权限与交互复查

本轮沿登录/账户切换、收藏与详情、个人资产、持仓编辑、日报、飞书绑定、新闻更新和后台任务继续检查；保留上一轮修改。未启动服务、执行生产构建、重启、部署或修改生产数据。

## 实际修复

| 问题 | 修复后的行为 |
| --- | --- |
| 资产刷新任务按 ID 查询未检查所属账户 | 对照当前账户校验，其他账户与游客读取私人任务均返回 404，避免泄露任务是否存在。 |
| 游客可以修改共用演示资产、生成日报和改变订阅设置 | 演示数据保持可读；写操作在后端要求有效会话，前端引导登录。游客点击飞书绑定也先打开登录框。 |
| 公共新闻采集和模型评分更新缺少权限检查 | 使用现有管理员身份校验，游客返回 401，普通账户返回 403；普通账户仍可浏览公共新闻。 |
| 并发点击或多标签页产生重复刷新任务 | 创建任务时串行检查并复用活动任务；同账户日报生成期间拒绝重复请求，失败后释放状态。 |
| 服务重启后任务永久显示 queued/running | 加载任务记录时将中断任务标记为失败并提示重新发起，已完成任务不受影响。 |
| 重复添加币种会把原持仓覆盖为默认数量/均价 | 保留 POST 的更新或新增行为，但仅更新显式提供的字段；前端重复添加提示转到持仓设置，避免整份默认表单覆盖已有资产。 |
| 持仓部分更新可写入 null，且未重新验证合并后的记录 | 拒绝必填字段的显式 null，允许省略字段及清空自定义仓位；合并后重新校验，串行执行持仓写操作。 |
| 取消非持仓币种的关注无效；预警阈值 0 读回变 70 | 按合并后的持仓状态应用关注规则，数据库读取保留合法的零值。 |
| 日报生成结果覆盖后来选择的时间范围 | 增加请求代次和提交锁，旧响应不会覆盖当前范围；后台读取也不会覆盖新生成结果。 |
| 切换币种或账户后仍显示旧状态，详情请求被正常身份刷新中断 | 详情按账户及条目重建状态；只把结果写入匹配币种，避免旧保存结果重置新币种表单。 |
| 设置或 OAuth state 保存失败仍返回成功 | 持久化失败明确报错，state 无法可靠消费时不会继续绑定；旧订阅值保持可读。 |
| 返回地址可包含反斜杠形式的跨站地址，新闻链接未限制协议 | 返回地址限制为站内路径，外部来源仅接受 HTTP(S)。 |
| 添加资产可重复提交，错误提示被弹窗遮挡 | 增加写操作锁、提交状态、小屏滚动及弹窗内错误提示；游客页面明确标注只读演示。 |

- `npm run typecheck`、`npm run lint`：通过。
- `npm test`：9/9 通过。
- 后端 `pytest evals -q`：224 项通过，另有 26 个子测试通过，无失败或跳过。本轮包含 13 项新增回归；此前未被 unittest 收集的 2 项函数式测试也已执行。[完整日志](functional-backend-tests.log)
- 测试输出有 10 条弃用警告，来自现有 FastAPI `on_event` 用法和 Starlette TestClient 的 httpx 兼容接口，没有隐藏或禁用检查。
- 产品质量门禁：6/6 通过。[结果](functional-product-gate.json)
- 浏览器采用修改后组件及隔离 API 夹具，覆盖 34 项桌面/平板/手机布局检查，以及登录引导、账户隔离、登录态详情、日报重复提交/范围竞态、输入法、存储不可用和请求失败等交互。34 项布局和 11 项交互均通过，未出现未捕获页面异常或遗漏接口夹具。具体记录见 [浏览器结果](functional-browser-results.json)。夹具用于验收，不冒充真实模型输出。
- 生产构建仍按项目约束未执行；没有验证上线后的真实 DeepSeek、飞书 OAuth 授权或外部链路。

## 仍需条件或设计决策

- 原报告中的域名/端口冲突、旧本地数据归属、密码 pepper 兼容迁移、剩余依赖告警和部署验收条件仍存在，见 [首轮报告](REPORT.md)。
- 账号删除横跨多份 SQLite/JSON 存储，目前缺少整体事务；中途磁盘失败可能导致部分删除。全面保证原子性需设计统一删除任务、恢复及并发写入协调，本轮未做存储架构迁移。
- 任务互斥与恢复按当前单进程服务实现；未来使用多个后端 worker 时，需要共享任务锁与执行状态。
